# Security Policy

## Supported Versions
| Version | Supported |
|---|---|
| 0.1.x | ✅ |

## Reporting a Vulnerability
Please direct all vulnerability reports privately to `security@divmora.com` or report via [GitHub Security Advisories](https://github.com/divmora/aws-das-processor/security/advisories/new). We adhere to a 48-hour response SLA.
